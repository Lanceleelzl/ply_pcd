# 高斯编辑用户功能验证清单

状态：2026-10-28 已约定的本轮功能开发已补齐，可以开始用户功能验证。开发完成不等于全部人工验收通过；下面的勾选项由实际操作结果决定。

## 启动

在项目根目录运行：

```powershell
pnpm run dev
```

使用独立 Chrome／Edge 打开 `http://127.0.0.1:5273/editor`。默认 API 端口为 8865。先用较小模型跑通整条流程，再验证 `source` 中的真实模型及多层数据。

## 第一轮：一条完整编辑流程

- [ ] **创建任务**：导入一个 Gaussian PLY，看到上传／服务端校验阶段和已用时间，预读完成后进入工作台；原文件不变。
- [ ] **显示与导航**：切换点云和高斯；适配视角、俯视、WASD、Shift、滚轮、中键均可操作；聚焦输入框时不误移动相机。
- [ ] **平面裁剪**：创建矩形或多边形，修改顶点、插点、删点，再保存。边界沿模型全高生效；多个保留区域取并集，再扣除所有剔除区域。
- [ ] **体积裁剪**：取点后添加球体／长方体，调整中心、大小及盒体旋转，保存后检查效果。紧贴 GPU 边界的显示以正式成果为准。
- [ ] **显示剖切**：启用三轴、长方体或原点平面剖切，再关闭恢复；仅改变场景显示，不应修改导出数据。
- [ ] **变换**：修改平移、旋转或等比缩放，保存后再处理；有未保存变换时应提示保存或恢复设置。
- [ ] **正式处理**：在「层级／抽稀」选择目标 LOD，点击「处理选中层级」，看到真实阶段和进度，完成后出现成果版本。
- [ ] **下载并重导入**：保存 PLY 到桌面验收目录，确认页面完成且文件非空，再导入为新任务检查点数与裁剪范围。这一步补充自动化尚未完成的原生保存窗口验收。

## 两个容易混淆的地方

- **抽稀工作层用于交互**。正式批处理读取勾选的原始 LOD，不会自动使用抽稀工作层替代原始输入。
- **显示剖切用于观察**。真正删减文件要保存「边界」规则后执行处理；不能把屏幕上被隐藏的数据理解为已经从成果中删除。

## 本轮验证边界

- 开发验收已经覆盖规则、历史、主要格式、坐标、异步恢复和 WebXR 场景保留链修复；当前基线为 40 项前端／引擎测试、24 项服务端专项、类型检查和生产构建。
