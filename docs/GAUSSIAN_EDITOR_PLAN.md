# 高斯编辑实施方案

## 目标和边界

对单个 Gaussian 模型或同一模型的 LOD 文件组进行浏览、抽稀、空间裁剪、整体变换、地理坐标编辑与查询，并导出独立成果。贴图融合、文字标注、图片标注及逐高斯涂改不在本模块范围。

## 数据和交互契约

1. 导入时探测格式、关联文件、层级、高斯数量、空间范围、轴向、单位和可用地理提示。未知值保持未知，不猜测 LOD 或 EPSG。同组层级必须能映射到共同局部坐标框架，否则禁止批量应用。
2. 只将一个用户选定的工作 LOD 加载到浏览器。大文件编辑时只加载点云预览、较低 LOD 或服务端抽稀得到的轻量工作层；普通大原始层不提供强行加载入口。Streamed SOG 当前仍把所选 LOD 整层解码至浏览器，超过 2,000 万高斯的层级同样禁用直接显示；真正按视野动态加载是后续独立验收项。原始层始终保留，正式裁剪在服务端把同一空间规则应用于选定原始 LOD，无须将这些层级载入浏览器。抽稀按目标数量或保留比例执行，输出明确记录来源和参数。
3. 2D 多边形边界沿模型全高裁剪，交互复用高斯合并的绘制、吸附、顶点编辑和精确坐标能力。3D 球体、旋转长方体按共同坐标框架记录中心、尺寸或半径、旋转以及保留或剔除规则。所有保留边界取并集，再减去所有剔除边界；没有保留边界时，以整个模型为保留范围。边界判定以高斯中心点为准。预览和导出须使用同一规则语义，不以工作 LOD 的高斯索引作为跨层规则。
4. XOY、XOZ、YOZ、轴向范围与长方体显示剖切只改变场景显示。执行裁剪才写出新数据；批量任务在启动时冻结规则版本和目标层级，逐层从原始数据处理。
5. 模型几何变换与地理锚点修改是不同操作。坐标查询展示场景坐标；仅在源 EPSG、原点、轴向和单位可信时展示投影坐标及 WGS84 经纬度。投影计算保持双精度，渲染使用局部原点；高度基准不自动转换。
6. 编辑历史覆盖边界、变换、原点、抽稀参数和目标 LOD。拖动手势合并为一步；撤销后新操作丢弃其后的重做分支。保存的历史可在刷新后恢复。生成的文件成果以版本关联，不通过撤销删除或覆盖。相机视角历史与模型编辑历史分开。
7. 独立导航控制器只依赖画布、相机、帧时间和可选场景尺度。支持 WASD 连续移动、Shift 加速、滚轮沿视线推进或后退、中键平移及左键转向；组合输入可同时生效。失焦、输入框或工具手柄操作时清理或阻断相应输入。
8. 顶栏下方场景占满页面；顶部工具条、左右按需浮窗、右上视角手柄、底部文字提示、右下场景统计。历史操作以独立按钮显示完整步骤及当前指针。
9. 上传、预读、转换、抽稀、加载、预览计算、逐层执行、导出和打包均展示当前阶段、文件或 LOD、耗时与错误。只有真实可统计进度显示百分比；服务端处理状态持久化，刷新后恢复。

## 格式契约

- 输入候选：Gaussian PLY、Compressed PLY、SOG、Streamed SOG、LCC、LCC2。LCC／LCC2 为只读输入，可选 LOD；编辑成果不写回原格式。
- 输出候选：PLY、Compressed PLY、SOG、Streamed SOG，SPZ 在项目锁定版本及样本验证后开放。单层编辑成果须标明来源层级；Streamed SOG 需重新生成并校验清单，不把单层文件冒充完整 LOD 组。
- 实际开放范围以项目锁定的 `@playcanvas/splat-transform` 版本和真实格式样本的往返测试为准。若目标格式无法保存全部坐标元信息，成果清单必须补足并明确说明。

## 实施顺序

1. 记录基线，核对锁定工具的读写与抽稀能力，建立编辑任务状态和格式样本。
2. 提炼导航、坐标、边界及数据集的公共能力；先接入高斯编辑，再分别核对原模块行为。
3. 建立独立任务入口、工作台、工作 LOD、场景信息和操作历史。
4. 实现抽稀、2D／3D 边界、显示剖切、预览和撤销／重做。
5. 实现冻结规则版本、选定层级逐层处理、持久进度、成果版本与导出。
6. 以单文件、LOD 组、LCC／LCC2 和大文件样本做往返、坐标、性能及浏览器验收。

## 验收规则

- 浏览器仅加载所选工作层；对大层抽稀后可选派生层编辑，原件完整。
- 2D 与 3D 边界及模型坐标修改可以撤销、重做和从历史面板恢复；刷新后历史、规则和当前指针一致。
- 同一冻结规则应用于未加载的其他层；每层输出的空间范围、点数和坐标经重新导入核对，失败层不伪装成完整成果。
- 键盘移动与滚轮、中键可以同时操作；输入框、裁剪手柄和失焦时相机不误动。
- 所有等待步骤状态可见，百分比有真实分母，重载页面后仍可看到服务端任务进度和成果。
- 各输入输出格式按实际往返能力开放，原文件与旧成果不被覆盖。
