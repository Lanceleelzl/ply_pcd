# 高斯编辑实施方案

## 目标和边界

对单个 Gaussian 模型或同一模型的 LOD 文件组进行浏览、抽稀、空间裁剪、整体变换、地理坐标编辑与查询，并导出独立成果。贴图融合、文字标注、图片标注及逐高斯涂改不在本模块范围。

## 数据和交互契约

单文件的抽稀入口默认折叠，LOD 文件组和数据集不显示新建抽稀控件。既有派生工作层仍可切换。

1. 导入时探测格式、关联文件、层级、高斯数量、空间范围、轴向、单位和可用地理提示。未知值保持未知，不猜测 LOD 或 EPSG。LOD 文件组上传后自动核验各层的 EPSG、offset、shift 和 scale；缺失或不一致时提示涉及的层级与原因，拒绝导入。既有任务仍可打开，跨层处理前按相同规则复核。工作台无需手动勾选坐标框架确认。
2. 只将一个用户选定的工作 LOD 加载到浏览器。大文件编辑时只加载点云预览、较低 LOD 或服务端抽稀得到的轻量工作层；普通大原始层不提供强行加载入口。Streamed SOG 使用 PlayCanvas 原生八叉树按视野加载；超过 2,000 万高斯的高层级仅在最粗层点数已知且不超过 500 万时允许在高斯预算内回退到同数据集的较粗 LOD 作交互预览，持续低帧率时逐档降低预算，界面明确提示预览精度，并区分源层总数与本帧提交绘制高斯数、应用显存估算及当前预算。开放高层入口需以真实样本验证长时间导航帧率及资源占用；未达标时继续禁用。原始层始终保留，正式裁剪在服务端把同一空间规则应用于选定原始 LOD，无须将这些层级完整载入浏览器。抽稀按目标数量或保留比例执行，输出明确记录来源和参数。
3. 2D 多边形边界沿模型全高裁剪，交互复用高斯合并的绘制、吸附、顶点编辑和精确坐标能力。3D 球体、旋转长方体按共同坐标框架记录中心、尺寸或半径、旋转以及保留或剔除规则。所有保留边界取并集，再减去所有剔除边界；没有保留边界时，以整个模型为保留范围。边界判定以高斯中心点为准。预览和导出须使用同一规则语义，不以工作 LOD 的高斯索引作为跨层规则。
4. XOY、XOZ、YOZ、轴向范围与长方体显示剖切只改变场景显示。执行裁剪才写出新数据；批量任务在启动时冻结规则版本和目标层级，逐层从原始数据处理。
5. 模型几何变换与地理锚点修改是不同操作。坐标查询展示场景坐标；仅在源 EPSG、原点、轴向和单位可信时展示投影坐标及 WGS84 经纬度。投影计算保持双精度，渲染使用局部原点；高度基准不自动转换。
6. 编辑历史覆盖边界、变换、原点、抽稀参数和目标 LOD。拖动手势合并为一步；撤销后新操作丢弃其后的重做分支。保存的历史可在刷新后恢复。生成的文件成果以版本关联，不通过撤销删除或覆盖。相机视角历史与模型编辑历史分开。
7. 独立导航控制器只依赖画布、相机、帧时间和可选场景尺度。支持 WASD 连续移动、Shift 加速、滚轮沿视线推进或后退、中键平移及左键转向；组合输入可同时生效。失焦、输入框或工具手柄操作时清理或阻断相应输入。
8. 顶栏下方场景占满页面；顶部工具条、左右按需浮窗、右上视角手柄、底部文字提示、右下场景统计。历史操作以独立按钮显示完整步骤及当前指针。
9. 上传、预读、转换、抽稀、加载、预览计算、逐层执行、导出和打包均展示当前阶段、文件或 LOD、耗时与错误。只有真实可统计进度显示百分比；服务端处理状态持久化，刷新后恢复。压缩 PLY／SOG 成果重新导入时可附带本模块坐标说明，以文件 SHA-256、格式和高斯数量绑定；仅对能安全还原的投影框架自动设置坐标。

- 平面边界必须是无重复顶点的简单多边形：非相邻边不得相交或相触，边段不得重叠；相邻边同向的共线插点允许保留。面积以首顶点为局部原点计算，避免大投影坐标导致合法小范围被误判为零面积。前端保存前与服务端保存、处理前使用相同规则。
- 旋转长方体使用闭边界，中心恰好位于盒面、棱或角上的高斯计入内部。点云预览与服务端逆旋转判定允许不超过「16 倍双精度机器精度 × 最大边长或中心相对坐标」的舍入容差；仅用于补偿四元数运算的末位误差，保留与剔除规则共用此判定。
- GPU 预览在同一局部坐标框架中判定旋转盒，四元数舍入容差按相同公式使用单精度机器精度。浮点误差带内的显示不作为正式裁剪依据，界面说明紧贴边界时以服务端处理成果为准；不改变服务端的双精度规则。
- 边界辅助线在投影前裁去相机近平面后方的部分；二维吸附与插点使用同一可见线段，后方顶点不参与命中或显示手柄。该显示裁切不修改模型空间规则或历史中的顶点。
- 体积中心、中心高度、球半径、长方体尺寸和旋转手柄分别检查自身深度；近平面后方或非有限投影的手柄隐藏，其余可见手柄保持可用。
- 工具条换行时，浮动面板顶部跟随工具条实际高度，不能遮住工具按钮；面板内容保留自身滚动。
- 只读场景提示和历史更新提示不得拦截浮窗按钮或场景手柄的鼠标事件；下载取消按钮仍保留交互。

## 格式契约

### 2026-10-26 操作流程补齐

- LOD 文件组上传前逐项显示文件名与对应层级，允许上下移动；文件与上传路径同步排序，不猜测文件名中的层级。
- 切换任务立即清空旧任务取点、边界草稿和坐标查询结果，并显示任务加载状态；异步响应不得覆盖其他任务。
- 正式处理前检查未保存的边界、坐标和变换草稿，提示先保存或取消；显示剖切不写入导出，不误称为裁剪规则。
- 成果版本的冻结编辑快照可恢复为新的编辑历史一步；不使用可能已分叉的历史索引猜测旧版本设置，不删除或重新生成已有成果。

- 成果流式保存提供主动取消。取消、网络中断、写盘失败或可信长度不匹配时中止本地写入，不提交残缺目标；写入关闭成功后才提示完成。响应有内容编码时不使用压缩传输长度计算保存进度。
- 上传提交至任务创建完成期间显示真实已用时间；成果选定保存位置后持续显示保存耗时，关闭文件阶段沿用同一计时，不把已接收 100% 当作保存完成。

- 输入候选：Gaussian PLY、Compressed PLY、SOG、Streamed SOG、LCC、LCC2。LCC／LCC2 为只读输入，可选 LOD；编辑成果不写回原格式。
- 输出候选：PLY、Compressed PLY、SOG、Streamed SOG，SPZ 在项目锁定版本及样本验证后开放。单层编辑成果须标明来源层级；Streamed SOG 需重新生成并校验清单，不把单层文件冒充完整 LOD 组。
- 实际开放范围以项目锁定的 `@playcanvas/splat-transform` 版本和真实格式样本的往返测试为准。若目标格式无法保存全部坐标元信息，成果清单必须补足并明确说明。

## 实施顺序

1. 记录基线，核对锁定工具的读写与抽稀能力，建立编辑任务状态和格式样本。
2. 提炼导航、坐标、边界及数据集的公共能力；先接入高斯编辑，再分别核对原模块行为。
3. 建立独立任务入口、工作台、工作 LOD、场景信息和操作历史。
4. 实现抽稀、2D／3D 边界、显示剖切、预览和撤销／重做。
5. 实现冻结规则版本、选定层级逐层处理、持久进度、成果版本与导出。
6. 以单文件、LOD 组、LCC／LCC2 和大文件样本做往返、坐标、性能及浏览器验收。

## 验收规则

- 浏览器仅加载所选工作层；对大层抽稀后可选派生层编辑，原件完整。
- 2D 与 3D 边界及模型坐标修改可以撤销、重做和从历史面板恢复；刷新后历史、规则和当前指针一致。
- 同一冻结规则应用于未加载的其他层；每层输出的空间范围、点数和坐标经重新导入核对，失败层不伪装成完整成果。
- 键盘移动与滚轮、中键可以同时操作；输入框、裁剪手柄和失焦时相机不误动。
- 所有等待步骤状态可见，百分比有真实分母，重载页面后仍可看到服务端任务进度和成果。
- 各输入输出格式按实际往返能力开放，原文件与旧成果不被覆盖。
