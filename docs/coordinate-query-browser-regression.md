## 操作与结果

1. 打开坐标查询，选择移动 A 点并进入场景取点。在可见模型 A 上点击后，出现「已按 ICP 矩阵换算」提示，生成以下业务坐标：

   ```text
   A: -0.330573171377182 -2.0280008316040044 7.710744857788086
   B: -2.9808521343181953 -4.018762569625203 -2.357540846955366
   ```

2. 两侧点标签均显示，记录的横向位置相同，纵向位置分别为 122.633 px 和 144.633 px，符合标签错开放置的 22 px 差值。
3. 隐藏模型 A，再进入场景取点并点击原位置，显示未命中提示，六项坐标保持不变。
4. 恢复模型 A，打开剖切面板并选择坐标轴模式，场景取点按钮禁用。关闭剖切面板后按钮恢复可用。
5. 清除点后，A／B 点标签均隐藏。

注意：仅打开剖切面板且模式仍为「关闭」时，不会进入剖切编辑状态，不能用此状态验证编辑互斥。屏幕点击位置取决于视口和相机，不应作为通用固定坐标复用。

## 2026-09-10 补充：B 取点与手柄拖动
